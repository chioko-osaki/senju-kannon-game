# 手で救え!千手観音 ―― 編集ガイド

プログラミングが初めての方でも、直しやすいようにファイルを分けています。
「ここを変えたい」と思ったら、下の表からファイルを探してください。

## ファイルの場所と役割

| やりたいこと | 編集するファイル |
|---|---|
| 制限時間・出現率などの数値を変えたい | `data/config.json` |
| 色・文字の大きさ・背景など見た目を変えたい | `css/style.css` |
| ゲームの動き・当たり判定などの仕組みを変えたい | `js/game.js` |
| スコアの保存の仕組みを変えたい | `js/storage.js` |
| TOP画面やボタンの文言・並びを変えたい | `index.html` |
| 「あそびかた」ページの文章を変えたい | `how-to-play.html` |
| 「あそびかた」ページ送りの動きを変えたい | `js/howto.js` |
| 効果音・BGMを追加したい | `sounds/` フォルダに音声ファイルを置く(下記参照) |

数値の調整だけしたい場合は、`data/config.json` 以外は触らなくて大丈夫です。

## data/config.json の中身

```json
{
  "gameSeconds": 42,        制限時間(秒)
  "spawnIntervalMs": 650,   何ミリ秒ごとに1つ落ちてくるか(小さいほど忙しくなる)
  "fallSpeedPxPerSec": 150, 落ちる速さ(大きいほど速い)
  "catchRadiusPx": 46,      キャッチ判定の広さ(大きいほど簡単)
  "devilChance": 0.25,      😈 が出る確率(0〜1。0.25 = 25%)
  "lotusChance": 0.03,      🪷 が出る確率(0〜1。0.03 = 約3%)
  "numbMs": 1000,           😈 に触れてしびれる時間(ミリ秒)
  "lotusBonus": 10          🪷 を取ったときに増える人数
}
```

※ JSONファイルには`json`の中に書いてあるようなコメント(説明書き)を書けないため、
　実際のファイルには数値だけが入っています。上の表を見ながら編集してください。
　数値を変えたら、ファイルを保存してブラウザを再読み込みするだけで反映されます。

## 音声(SE・BGM)を追加する方法

`sounds/` フォルダに `.mp3` や `.wav` ファイルを置いてください。
現時点ではゲーム側で音を鳴らす処理はまだ入っていないので、
音を追加する際は `js/game.js` に以下のような形で読み込み・再生の処理を追加してください。

```js
const catchSound = new Audio('sounds/catch.mp3');
// キャッチした瞬間に catchSound.currentTime = 0; catchSound.play(); のように呼び出す
```

## 動作確認について(重要)

- **GitHub Pages にアップロードした状態**では、そのままブラウザで開けば正常に動きます。
- **自分のパソコンでファイルをダブルクリックして開いた場合**(`file://` から開いた場合)、
  ブラウザの制限により `data/config.json` が読み込めないことがあります
  (その場合は既定値でゲームが動くので、遊べなくなることはありません)。
- ローカルで確認しながら細かく調整したい場合は、簡易サーバーを使うと確実です。
  - 例:VSCode の拡張機能「Live Server」を使って `index.html` を開く
  - 例:ターミナルで `python -m http.server` を実行してから `http://localhost:8000` を開く
